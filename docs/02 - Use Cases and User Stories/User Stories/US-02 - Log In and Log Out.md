# US-02 - Log In and Log Out

## User story

As a student, I want to log in and log out so that nobody else can see my planner.

| Field | Value |
|---|---|
| Priority | Highest |
| Sprint # | TBD |
| Story Points | To be agreed in Planning Poker |

## Acceptance criteria

- Given I have an account, when I enter the right email and password, then I go to my home page.
- Given I enter the wrong email or password, when I click Log In, then I see "Email or password is wrong" and stay on the login page.
- There is a Log Out button on every page. After I click it I go back to the login page.
- After I log in I only see my own items, never another student's.
