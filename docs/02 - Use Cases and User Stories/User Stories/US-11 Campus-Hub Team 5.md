# US-11: Campus-Hub Team 5

## User story

As a student, I want to turn off the daily reminder email so that I don't get emails I don't want.

| Field | Value |
|---|---|
| Priority | Low |
| Sprint # | TBD |
| Story Points | To be agreed in Planning Poker |

## Acceptance criteria

- The Settings page has an on/off switch for the daily email.
- Given I turn it off, then I stop getting the email starting the next day.
- Given I turn it back on, then I start getting it again.
- The daily email is on by default for new accounts.
