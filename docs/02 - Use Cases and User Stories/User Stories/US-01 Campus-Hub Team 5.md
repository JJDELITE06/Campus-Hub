# US-01: Campus-Hub Team 5

## User story

As a student, I want to create an account with my name, email, and password so that my planner is saved and only I can see it.

| Field | Value |
|---|---|
| Priority | Highest |
| Sprint # | TBD |

## Acceptance criteria

- The sign-up page has boxes for name, email, password, and confirm password.
- Given I fill in every box correctly, when I click Sign Up, then my account is created and I go to my home page.
- Given my email is already used by another account, when I click Sign Up, then I see an error message and no new account is made.
- The password has to be at least 8 characters and both password boxes have to match.
- The password is stored hashed, not as plain text.
