# US-13 - Weekly Calendar View (new)

## User story

As a student, I want to see my assignments and tests on a calendar so that I can see how much is due on each day.

| Field | Value |
|---|---|
| Priority | Medium |
| Sprint # | TBD |
| Story Points | To be agreed in Planning Poker |

## Acceptance criteria

- There is a Calendar page that shows one week at a time.
- Each item shows on the day it is due.
- Next and Previous buttons move to the next or last week.
- Given I click an item on the calendar, then it opens so I can see the details.
