# US-07 - Edit an Item

## User story

As a student, I want to edit an item after I add it so that I can fix mistakes or change a due date.

| Field | Value |
|---|---|
| Priority | High |
| Sprint # | TBD |
| Story Points | To be agreed in Planning Poker |

## Acceptance criteria

- Every item has an Edit button that opens the form with the current info already filled in.
- Given I change something and click Save, then the item is updated in my list and calendar.
- Given I click Cancel, then nothing changes.
- Given the item is a repeating event, when I click Edit, then I can choose "Just this one" or "All of them."
