# US-05: Campus-Hub Team 5

## User story

As a student, I want to add a one-time item, like an assignment, test, project, or meeting, with a due date so that I can keep track of everything I have to do in one place.

| Field | Value |
|---|---|
| Priority | Highest |
| Sprint # | TBD |
| Story Points | To be agreed in Planning Poker |

## Acceptance criteria

- The Add form has: title, type (Assignment, Test/Quiz, Project, Meeting, Other), class (optional), due date and time, location (optional), and notes (optional).
- Given I leave the title or due date empty, when I click Save, then I see an error and it is not saved.
- Given I fill in the form correctly, when I click Save, then the item shows up in my list in order by due date.
