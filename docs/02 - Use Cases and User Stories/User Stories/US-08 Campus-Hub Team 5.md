# US-08: Campus-Hub Team 5

## User story

As a student, I want to mark an item as complete and still see it in my list so that I can see what I've already finished.

| Field | Value |
|---|---|
| Priority | High |
| Sprint # | TBD |
| Story Points | To be agreed in Planning Poker |

## Acceptance criteria

- Every item has a checkbox.
- Given I check the box, then the item shows as done (crossed out or grayed out) and stays in the list.
- Given I uncheck the box, then the item goes back to not done.
- There is a "Hide completed" option so I can hide finished items if I want to.

Definition of Done: see [Definition of Done - Common.md](Definition%20of%20Done%20-%20Common.md)
