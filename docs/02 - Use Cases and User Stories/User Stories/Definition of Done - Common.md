## Definition of Done (applies to every user story)

- All of the story's acceptance criteria (in its US-NN file) have been checked and work.
- The code is on its own branch and merged into main with a pull request that at least 1 teammate reviewed and approved.
- Tests are written for the story and all tests pass.
- It works in a browser on a phone and on a computer.
- The story is moved to Done on our project board.
