# US-09 - Filter by Item Type

## User story

As a student, I want to filter what shows on my screen, for example only classes, only work shifts, or only club meetings, so that I can focus on one part of my schedule at a time.

| Field | Value |
|---|---|
| Priority | Medium |
| Sprint # | TBD |
| Story Points | To be agreed in Planning Poker |

## Acceptance criteria

- There is a filter with one choice for each type (Assignment, Test/Quiz, Project, Class, Club/Activity, Job shift, Meeting, Other).
- Given I pick a type, then only items of that type show.
- Given I pick "Show all", then every item shows again.
- The filter works on both the list and the calendar.
