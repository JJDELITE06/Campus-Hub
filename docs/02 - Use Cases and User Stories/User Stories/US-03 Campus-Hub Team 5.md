# US-03: Campus-Hub Team 5

## User story

As a student, I want to see my upcoming assignments and tests for one class at a time so that I can focus on that class.

| Field | Value |
|---|---|
| Priority | Medium   (The calendar idea that was in this box is now its own story, US-13.) |
| Sprint # | TBD |
| Story Points | To be agreed in Planning Poker |

## Acceptance criteria

- There is a class dropdown above my list.
- Given I pick a class, when the list updates, then only that class's items show, soonest due date first.
- Given I pick "All classes", when the list updates, then everything shows again.
