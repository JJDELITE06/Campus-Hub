# US-06: Campus-Hub Team 5

## User story

As a student, I want to add a repeating event, like a class, club meeting, or work shift, so that I don't have to type it in every week.

| Field | Value |
|---|---|
| Priority | Medium   (This one might be too big for one sprint. We may need to split it during Planning Poker.) |
| Sprint # | TBD |
| Story Points | To be agreed in Planning Poker |

## Acceptance criteria

- The form lets me pick the days of the week it repeats (for example Mon/Wed/Fri), a start time, an end time, a start date, and an end date.
- The type can be Class, Club/Activity, Job shift, or Other.
- The end date is required so the event doesn't repeat forever.
- Given I save a repeating event, when I look at my list or calendar, then it shows up on every matching day between the start and end dates.
