# US-04 - Delete Items

## User story

As a student, I want to delete items I don't need anymore so that my list doesn't get cluttered.

| Field | Value |
|---|---|
| Priority | High |
| Sprint # | TBD |
| Story Points | To be agreed in Planning Poker |

## Acceptance criteria

- Every item has a Delete button.
- Given I click Delete, when the "Are you sure?" box shows up and I click Yes, then the item is gone from my list and calendar.
- Given I click Delete and then Cancel, then nothing is deleted.

Definition of Done: see [Definition of Done - Common.md](Definition%20of%20Done%20-%20Common.md)
