# UC-15 Campus-Hub Team 5

| Use Case – 15 | Turn reminder emails on or off  (goes with US-11) |
|---|---|
| **Primary Actors** | Sally, Carl |
| **Flow of events** | 1. User opens the Settings page.<br>2. System shows a "Daily reminder email" switch (on or off).<br>3. User changes the switch and clicks "Save."<br>4. System saves the setting and shows "Settings saved." |
| **System** | Class management web site |
| **Preconditions** | User is logged in (UC-02). |
| **Postconditions** | The setting is saved. Emails stop or start again the next day. |
| **Business Relevance** | Some students don't want a daily email. Letting them choose keeps them using the app. |
| **Dependencies** | UC-02, UC-14 |
| **Extensions** | 3a. User leaves the page without clicking Save: the setting does not change. |
| **Priorities** | Low |
| **Nonfunctional requirements** | New users start with reminder emails turned on.<br>Works in supported browsers / platforms (phone, PC, Mac). |
