 # Tech Stack

The programming language and other technologies we will use to build our program.

## Programming Language: Python

Python is a language that all of us have some experience with, so it should have a lower learning curve for the group. We will use it as much as possible unless it cannot support something we need to do.

## Web Framework and Database: Django and SQLite

We do not yet have a database course or much database experience. Django can simplify database work by letting us use familiar Python syntax and manage stored data through Python objects. It can create database tables as needed and supports storing, updating, and deleting objects without requiring us to write database queries for every operation. We will use SQLite as the database.
